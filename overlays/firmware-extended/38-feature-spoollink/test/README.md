# Проверки устойчивости назначения катушки

Запуск из корня репозитория, без дополнительных пакетов:

```sh
python3 -B -m unittest discover -s overlays/firmware-extended/38-feature-spoollink/test -v
```

Тесты используют настоящие компоненты SpoolLink для Moonraker и Klipper.
Сетевые запросы, хранение Spoolman и передача команд заменены объектами в
памяти. Обработчик `filament_detect/set` извлекается из настоящего патча.
Подключение к принтеру и изменение рабочей базы не выполняются.

Проверяются повторное чтение прежнего UID, порядок получения UID и номера
катушки, повторные события, последовательное выполнение поиска на канале,
смена метки, пустое чтение, извлечение, неизвестный и неоднозначный UID,
кэш, выбор инструмента, отключение Klipper и ручная отвязка.

Для `Clear` проверяются отмена поиска, удаление кэша, сохранение второго UID,
ожидание уже отправленной записи привязки и отклонение запроса назначения,
который уже отправлен в Klipper. Отдельно проверяется новое ручное назначение
того же UID после очистки.

Тесты основаны на сценариях, рассмотренных в
[PR #655](https://github.com/paxx12-snapmaker-u1/SnapmakerU1-Extended-Firmware/pull/655).
Из [PR #724](https://github.com/paxx12-snapmaker-u1/SnapmakerU1-Extended-Firmware/pull/724)
использовано изменение `is_clear=has_params` для пустых ответов OpenRFID.
Текущие механизмы `CARD_EVENT_TIME`, ручной отвязки и `force_generic_vendor`
сохраняются.

Снимок UID, времени чтения и поколения назначения проверяется ещё раз в
Klipper перед применением ответа. Команда `SPOOLLINK_CLEAR` увеличивает
поколение до очистки канала и отправки запроса на отвязку. Это позволяет
отклонить ответ, который Moonraker уже успел отправить до ручной очистки.
Макрос `SET_SPOOL_ID` сохраняет прежние параметры и поведение кнопок интерфейса.

Если сброс номера приходит раньше уведомления о чтении, компонент проверяет
актуальное состояние запросом в Klipper. Ответ такого запроса не должен
перезаписывать более новое состояние, полученное через подписку.

Проверки на принтере остаются обязательными: чтение вручную и при загрузке,
обе метки катушки, реальное извлечение, смена инструмента, короткая печать,
недоступность Spoolman и повторение после перезагрузки. Тесты не восстанавливают
катушку по пустому UID без подтверждающего чтения. При ошибке сетевой отвязки
автоматическое восстановление UID блокируется в текущем процессе Moonraker;
сохранение такой блокировки между его перезапусками требует отдельного решения.
